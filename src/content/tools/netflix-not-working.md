Netflix 打不开有五种完全不同的症状,对应的原因和解法也不同。
先花十秒钟对号入座,比盲目换节点快得多。

## 五种症状对照

| 你看到的 | 真实原因 | 该做什么 |
| --- | --- | --- |
| 只有自制剧,版权剧不显示 | 出口 IP 被判定为代理 | 换节点(解锁类) |
| 提示「正在使用代理」类错误 | IP 在平台黑名单 | 换节点(解锁类) |
| 片库不是预期的国家 | IP 实际归属地与节点名不符 | 换节点并核对实际出口地区 |
| 能播但一直缓冲 | 带宽不足或线路拥堵 | 看线路与时段(带宽类) |
| 画质锁在 480p | 带宽不足或平台判定 | 先测带宽(带宽类) |

**解锁类换节点,带宽类看线路**——这两条路径不要混着走,是解决问题最快的原则。

## 解锁类:为什么换节点有用

Netflix 用商业 IP 数据库判断两件事:IP 属于哪个版权区、IP 是不是代理出口。
第二项判定失败时,平台不会直接拒绝你,而是**降级为只提供自制内容**——
因为自制剧全球有版权,不涉及地区授权问题。

这也给了你一个零成本自检法:

- 自制剧能播 + 版权剧不显示 → 解锁失败,换节点;
- 两者都打不开 → 不是解锁问题,是连接问题,
  转[能测速但打不开网页](/tutorial/connected-but-no-internet/)。

换节点时优先选机场标注了「解锁」「流媒体」的节点——这类节点通常用了质量更好的
出口 IP,原理见[原生 IP 词条](/protocol/native-ip/)。

## 带宽类:缓冲和画质问题

能正常播放说明解锁已经成功,剩下的是带宽问题:

1. **只在晚上卡** → 跨境线路在晚高峰拥堵,与节点 IP 无关。
   这是线路类型决定的上限,见[专线机场推荐](/airport/dedicated-line/);
2. **全天都卡** → 节点负载或套餐限速,换节点或查套餐条款;
3. **画质一直上不去** → 4K 需要 25Mbps 以上的**稳定**带宽,峰值高没用,
   波动会直接触发降码率。

## 设备之间表现不一致

同一个节点,手机能看电视不能看,几乎都不是机场的问题:

- **电视/机顶盒没走代理**——它们通常不读手机或电脑上的代理设置,
  需要在路由器层面处理;
- **DNS 不一致**——设备使用了不同的 DNS,解析结果与代理出口不匹配,
  会导致地区判定异常;
- **App 与网页判定策略略有差异**——先用网页端验证解锁是否成功,再排查 App。

## 为什么解锁节点会「过期」

平台的代理 IP 库持续更新,一个节点被越多人用,进入黑名单的概率越高。
所以任何「永久解锁」的承诺都不成立——这也是本站
[不提供解锁保证清单](/airport/streaming/)的原因。

可持续的做法是:选机场时看解锁宣称与节点标注(挑选方法见
[流媒体解锁机场](/airport/streaming/)),用最短周期实测你要看的那个平台和地区,
并接受它需要偶尔换节点这一事实。
