faq:
  - q: 机场能看到我访问的具体内容吗?
    a: HTTPS 网站看不到内容,因为加密是端到端的。能看到的是域名层面的信息:你连了哪个站、什么时候、传了多少数据。明文 HTTP 的内容则可见,但现在这类站点已经很少。
  - q: 机场会保存连接日志吗?
    a: 无法一概而论,也无法从用户侧验证。运营上通常需要一些连接记录来排查故障和执行套餐限制;是否长期留存、留存哪些字段,取决于服务方策略。看到「绝对不记录任何日志」的宣称,把它当作声明而不是事实。
  - q: 机场审计是什么意思?
    a: 指服务方对流量做的自动检测与限制,常见的是拦截 BT 下载、垃圾邮件发送、端口扫描等——这些行为会给服务器 IP 招来投诉甚至下架。审计针对的是特定行为模式,不等于逐条记录你的访问内容。
  - q: 为什么机场要禁止 BT 下载?
    a: 大流量 P2P 会拖垮共享带宽,更重要的是版权投诉会导致机房下架服务器。这是几乎所有共享型服务的通用限制,写在多数服务条款里,不是针对个人。
  - q: 怎么判断一家机场的隐私态度?
    a: 看三样可查证的东西:有没有公开的隐私与日志政策、条款里对审计范围的描述是否具体、出问题时的沟通是否透明。这三项都能在购买前看到,比任何「无日志」口号更有参考价值。
  - q: 用了代理就完全匿名了吗?
    a: 不是。代理只是把你的流量出口换了个位置,你的账号登录状态、浏览器指纹、Cookie 依然会标识你。追求匿名和追求访问畅通是两个目标,机场解决的是后者。

> **本文性质**:通用技术原理与编辑观察的整理,不针对任何具体品牌,
> 也不对任何服务的日志政策做真伪判断——那超出用户可验证的范围。

这是使用代理服务时最该想清楚、也最容易被两种极端说法带偏的问题:
一边是「机场什么都看得到,太危险」,一边是「我们绝对不记录任何日志」。
**两句话都不准确。**

## 第一层:能看到什么(技术事实)

流量经过机场的服务器,所以在技术上:

| 信息 | 是否可见 |
| --- | --- |
| HTTPS 页面的具体内容、密码 | 看不到(端到端加密) |
| 你连接了哪些域名 | 看得到 |
| 连接时间、频率、流量大小 | 看得到 |
| 你的真实来源 IP | 看得到 |
| 明文 HTTP 的内容 | 看得到 |

这部分是**协议决定的**,与服务商的品德无关,换任何一家都一样——
包括[免费节点](/free-nodes/safety/),那里的对方还是身份不明的人。

## 第二层:会不会记录(策略问题)

「能看到」和「会记录」是两回事,后者取决于服务方的策略,而**用户无法验证**。

需要理解的是,正常运营本身就需要一部分记录:

- 统计流量以执行套餐额度与[倍率](/protocol/node-multiplier/);
- 短期连接记录用于排查故障和处理工单;
- 同时在线设备数的判定。

所以「完全不产生任何记录」在工程上并不现实。看到这类绝对化宣称时,
合理的态度是:**把它当作一句声明,而不是一个可核实的事实。**
这与本站对待其他官方宣称的方式一致——见[编辑规范](/about/editorial/)。

## 审计规则是另一回事

中文机场社区常说的「审计」,指的是**服务方对特定行为的自动检测与限制**,
典型包括:

- BT / P2P 大流量下载;
- 垃圾邮件发送、端口扫描;
- 明显的攻击类流量。

这些行为会给服务器 IP 招来投诉,严重时机房会直接下架整台机器——
一台机器上还有其他用户,所以限制它是共享型服务的通用做法,
多数服务条款里都写了。

**审计针对的是行为模式,不等于逐条记录你访问了什么。**
把两者混为一谈,容易得出错误结论。

## 怎么评估一家机场的隐私态度

用户无法验证后台,但有三样东西**购买前就能看到**:

1. **有没有公开的隐私与日志政策**——写了不代表一定执行,
   但连写都不写,连讨论的基础都没有;
2. **审计范围的描述是否具体**——「禁止违法行为」是套话,
   「禁止 BT、禁止端口扫描」是可执行的规则,后者说明对方认真对待过这件事;
3. **沟通是否透明**——故障时是否发公告、说明原因。
   这一项同时也是[稳定性判断](/airport/stability/)的信号之一。

三项都不合格的服务,风险不只在隐私层面,建议一并对照
[跑路前兆清单](/risk/exit-scam-signals/)。

## 一个务实的心态

代理解决的是**访问畅通**,不是**匿名**。你的登录状态、浏览器指纹、Cookie
依然在标识你;换出口 IP 不会让这些消失。

所以合理的做法是分场景:高敏感操作走你信任的网络与设备,
代理用在它擅长的地方。**把所有隐私预期都押在一条代理线路上,
无论付费与否都不成立。**
