  - q: 订阅更新后节点全部消失了怎么办?
    a: 多数是套餐过期或流量耗尽后服务端返回了空配置,先查账号状态。也有机场在维护时短暂返回空列表,等一段时间再更新一次。保留旧配置不要立刻删除,可以先用着。
  - q: 订阅链接被重置后旧链接还能用吗?
    a: 不能。重置会生成新的订阅地址,旧地址立即失效。这也是重置功能的用途——订阅链接泄露时用它止损,重置后在每台设备上重新导入即可。
  - q: 同一个订阅可以导入多个软件吗?
    a: 技术上可以,但要注意套餐的同时在线设备数限制。多端同时连接超过上限时,表现可能是某台设备莫名连不上,而不是明确报错。
  - q: 机场订阅需要每天更新吗?
    a: 不需要。机场调整节点后更新一次即可,多数客户端也支持设置自动更新间隔。频繁手动更新没有额外好处,个别机场还会对高频请求做限制。

订阅更新失败时,客户端给出的报错信息通常已经指明了方向。
这一页按报错分类处理,你可以直接跳到对应的那一段。

## 按报错对症

| 报错 / 现象 | 最可能的原因 | 处理 |
| --- | --- | --- |
| 403 / 未授权 | 套餐过期、流量耗尽、订阅被重置 | 登录用户中心查状态,必要时重新复制链接 |
| 404 / 链接无效 | 订阅地址已失效或复制错误 | 回用户中心重新复制完整链接 |
| 提示流量不足 | 额度用尽 | 续费或等重置周期;注意节点倍率的消耗 |
| 返回网页代码 / HTML | 复制的是页面地址,不是订阅地址 | 找「复制订阅链接」按钮,而不是复制浏览器地址栏 |
| 内容空白 / 没有节点 | 服务端返回空配置(常见于欠费或维护) | 查账号状态,稍后重试,先别删旧配置 |
| 解析失败 / 格式错误 | 订阅格式与导入位置不匹配 | 换成客户端要求的格式(Clash 格式 / 通用格式) |
| 更新超时 / 网络错误 | 订阅域名在当前网络被拦截 | 换网络重试,或开启「通过代理更新订阅」 |

## 三个高频细节

### 一、复制的必须是订阅地址

用户中心里「订阅链接」和「用户中心页面地址」是两回事。
把页面地址填进客户端,得到的就是一堆 HTML——也就是「返回网页代码」这个现象。
正确做法是点击**复制订阅链接**按钮。

部分机场不在页面上展示订阅链接,需要联系在线客服索取——
本站收录的 16 家里,官方资料普遍标注了这一点,详见 [Clash 机场推荐](/airport/clash/)
里关于订阅格式的说明。

### 二、格式要与客户端匹配

同一个账号通常能导出多种格式。常见的对应关系:

- **Clash / Clash Verge / Mihomo 内核** → Clash 格式(YAML 配置);
- **Shadowrocket、v2rayN 等** → 通用格式(Base64)或各自专用格式,
  多数也能吃 Clash 格式。

格式不对时的典型报错就是「解析失败」。机场后台一般有多个格式的按钮,换一个再试。

### 三、更新超时不是链接坏了

订阅域名有时会在特定网络下被拦截,表现为更新超时,但链接本身有效。两种解法:

1. **换网络**:切到手机流量再更新一次,能成功就说明是网络环境问题;
2. **让客户端走代理更新**:多数客户端有「使用代理更新订阅」类选项,
   前提是当前至少有一个可用节点。

## 订阅链接的正确管理

订阅链接是**账号凭证**,不是分享素材:

- 不发群、不发朋友——他人可消耗你的流量,还可能因多地登录触发风控;
- 泄露后立刻在用户中心**重置订阅**,重置后旧链接立即失效,各设备重新导入;
- 多设备使用前,先确认套餐的同时在线设备数限制。
