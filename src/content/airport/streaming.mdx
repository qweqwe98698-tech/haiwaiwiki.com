流媒体解锁是机场宣传里最常出现、也最容易被误解的卖点。
误解的核心是:**很多人以为解锁靠速度,其实解锁只靠 IP。**

## 解锁到底是怎么判定的

打开 Netflix 时,平台会用商业 IP 数据库判断两件事:

1. **这个 IP 属于哪个国家/地区**——决定你能看到哪个版权区的片库;
2. **这个 IP 是不是代理出口**——被判定为代理时,限制为仅自制内容,或直接报错。

第二点是机场用户翻车的主要原因,它取决于 IP 的类型与滥用历史,
和你买的套餐带宽完全无关——原理见[原生 IP 词条](/protocol/native-ip/)。

| 症状 | 含义 | 处理方向 |
| --- | --- | --- |
| 只显示自制剧 | IP 被判定为代理 | 换未被标记的节点 |
| 提示代理错误(如 F7111) | IP 明确在黑名单 | 换节点,同区其他线路 |
| 片库是另一个国家的 | IP 归属地与预期不符 | 检查节点实际落地地区 |
| 能播但一直缓冲 | 解锁成功、带宽不足 | 看线路类型与晚高峰 |
| 画质锁在 480p | 带宽或平台限制 | 与解锁无关,查带宽 |

学会区分这五种症状,你就不会在「该换节点」的时候去研究「是不是要换机场」。

## 自制剧与版权剧:一个有用的判断法

Netflix 自制内容在全球都有版权,所以**即使 IP 被识别为代理,自制剧通常仍能播放**。
这给了你一个零成本的自检方法:

- 自制剧能播、版权剧不能播 → 解锁失败(IP 被标记),换节点;
- 两者都不能播 → 通常不是解锁问题,而是连接或分流问题,
  按[延迟与连接的分层排查](/airport/high-latency/)处理。

## 地区怎么选

| 地区 | 片库特点 | 注意 |
| --- | --- | --- |
| 日本 | 动画资源丰富,延迟低 | 大陆用户常用首选 |
| 港台 | 中文字幕友好 | 部分平台片库较小 |
| 新加坡 | 延迟与片库较均衡 | 节点数量通常少于日港 |
| 美国 | 剧集与电影最全 | 延迟最高,IP 被标记比例也高 |

选择顺序建议是**先按内容需求定地区,再在该地区里挑可用节点**,
而不是先挑延迟最低的节点再指望它能解锁。

## 三步验证法(买最短周期后立刻做)

1. **测自制剧与版权剧各一部**——用上面的判断法确认是否真解锁;
2. **测你真正要看的那个平台和那个区**——Netflix 能解锁不代表 Disney+ 也能;
3. **在晚高峰重测一次画质**——解锁成功但高峰期只能 480p,同样不满足需求,
   这时要看的是线路类型,见[专线机场推荐](/airport/dedicated-line/)。
