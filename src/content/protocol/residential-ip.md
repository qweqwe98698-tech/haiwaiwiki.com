**住宅 IP**(也叫家宽 IP)指运营商分配给**家庭宽带用户**的 IP 地址。
它在各类 IP 数据库里被标记为 residential 类型,与 hosting/datacenter 相对。

## 为什么类型会影响可用性

风控系统判断一个访问是否可疑时,IP 类型是重要信号:

| IP 类型 | 背后通常是 | 风控信任度 |
| --- | --- | --- |
| 住宅 | 真实家庭用户 | 最高 |
| 移动网络 | 手机用户 | 较高 |
| 数据中心 / 机房 | 服务器,也可能是代理 | 较低 |
| 已知代理出口 | 明确的代理服务 | 最低 |

绝大多数机场节点属于**数据中心 IP**——这是成本决定的。
这类 IP 本身没有问题,但当某个 IP 段被大量代理用户共享后,
风控评分会持续恶化,表现就是频繁人机验证甚至直接拒绝。

## 与原生 IP 的关系:两个独立维度

这是最常被混淆的一点:

- **原生 / 广播**:说的是**注册地与实际位置是否一致**;
- **住宅 / 数据中心**:说的是 **IP 的类型**。

两者可以自由组合。一个香港机房用香港注册 IP 段——原生,但仍是数据中心类型;
一条家庭宽带出口——住宅,而且通常天然就是原生的。

判断解锁能力时**两个维度都要看**,详细说明在[原生 IP 词条](/protocol/native-ip/)。

## 成本:为什么它不出现在几十元的套餐里

住宅 IP 的供给受真实家庭宽带数量限制,无法像机房 IP 那样批量采购,
市面上通常按流量计费,单价与机场套餐完全不是一个量级。此外:

- **上行带宽受限**——家庭宽带的上行远小于机房,不适合大流量场景;
- **稳定性受限**——家庭线路会断电、重启、重新拨号。

所以看到低价套餐宣称「住宅 IP」时,合理的反应是追问细节:
是全时段住宅 IP,还是仅个别节点、或按需切换?
这类宣称本站无法验证,处理方式与其他官方宣称一致——照录并标注未验证。

## 谁真的需要它

- **需要住宅 IP**:多账号运营、对风控极其敏感的平台操作
  (例如 [TikTok 多账号](/tools/tiktok-not-working/)),这类场景往往还要求
  **静态**住宅 IP 以保持身份稳定;
- **不需要住宅 IP**:网页浏览、流媒体、日常 AI 对话。
  这些场景用质量好的原生机房 IP 就够,把预算花在
  [线路稳定性](/airport/stable/)上收益更大。

## 一个务实的判断顺序

遇到「某服务用不了」时,不要一步跳到住宅 IP:

1. 先换机场里标注解锁/AI 的节点(多为原生机房 IP);
2. 不行再考虑更换服务商;
3. 只有在确认是 IP 类型层面的限制、且该用途值得这个成本时,
   才考虑住宅 IP 方案。

绝大多数人停在第一步就解决了。相关排查见
[ChatGPT 无法访问](/tools/chatgpt-not-working/)与
[Netflix 无法播放](/tools/netflix-not-working/)。
