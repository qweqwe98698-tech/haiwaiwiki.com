**原生 IP**(Native IP)指:IP 段的注册归属地(WHOIS 信息)与服务器实际所在地一致,
且由当地网络运营方正常分配。它是理解「为什么代理连上了,ChatGPT/Netflix 还是不能用」
的核心概念。

## 对照着理解:原生的反面是「广播」

机房扩容时,把注册在 A 国的 IP 段通过 BGP 广播到 B 国机房使用,是常见的低成本做法。
这样的 IP 在数据库里注册地是 A 国、实际延迟特征却是 B 国——即「广播 IP」。

| 概念 | 说的是什么 | 典型例子 |
| --- | --- | --- |
| 原生 IP | 注册地 = 所在地 | 香港机房用香港注册的 IP 段 |
| 广播 IP | 注册地 ≠ 所在地 | 美国注册的 IP 段广播到香港机房 |
| 数据中心 IP | IP 类型属于机房/托管 | 绝大多数机场节点 |
| 住宅 IP | IP 类型属于家庭宽带 | 家宽出口、住宅代理 |

「原生/广播」与「数据中心/住宅」是两个独立维度,可以组合出现。

## 为什么服务商在意它

流媒体与 AI 服务的风控都依赖商业 IP 数据库(定位、类型、风险评分):

- **定位一致性**:Netflix 按 IP 判定你所在的版权区域;注册地与网络特征矛盾的 IP 容易被归入代理名单;
- **类型与风险评分**:ChatGPT 这类服务对数据中心 IP、已知代理出口的容忍度低,
  高风险 IP 段会触发人机验证、降级甚至封禁;
- **滥用历史**:一个 IP 段被大量代理用户共享后,行为特征会让整段 IP 的评分恶化——
  这就是「昨天还能用、今天全不行」的常见原因。

原生 IP 在这三项上都占优:注册一致、通常由本地运营商分配、共享滥用比例相对低。

## 对机场用户的实际含义

1. **解锁类需求(流媒体/AI)优先看 IP 质量,而不是速度**。一个延迟 300ms 的原生 IP 节点,
   解锁能力可能远好于 50ms 的广播 IP 节点;
2. **「原生」是概率优势,不是保证**。IP 数据库每天都在更新,解锁状态是动态的;
3. **机场通常只有部分节点是原生 IP**,且会在节点名里标注(如「解锁」「流媒体」「GPT」字样),
   用对节点比换机场更先见效——具体排查流程见 [ChatGPT 无法访问怎么办](/tools/chatgpt-not-working/);
4. IP 质量与[线路类型](/protocol/iplc-vs-iepl/)无关:专线解决路怎么走,原生 IP 解决出口是谁,
   两者独立,都好才是真的好。
